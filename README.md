# Tripva - Travel Application

Tripva is a travel application designed to help users explore destinations, search for places, plan trips, and manage their travel preferences.

## 📌 Project Overview

Tripva provides a convenient platform for users to discover travel destinations and organize their trips. The project focuses on user-friendly navigation, destination discovery, trip planning, and a smooth travel experience.

## 🎯 Objectives

* Explore and discover travel destinations
* Search for destinations easily
* Filter and sort destinations based on requirements
* View detailed destination information
* Create and manage travel plans
* Save favorite destinations
* Manage user profile information
* Provide a responsive and user-friendly interface
* Ensure application quality through manual testing
